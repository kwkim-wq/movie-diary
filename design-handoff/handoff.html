Movie Diary

개인 영화 기록 앱 · 미니멀 시네필 DB · 다크 모드 · Letterboxd-ish. 이 한 파일에 토큰 / 컴포넌트 / 인터랙션 / 구현 노트가 모두 들어 있습니다.

개요 디자인 토큰 컴포넌트 3 화면 인터랙션 구현 노트 TMDB API 로컬 스토리지 최종 작업 브리프

0 · 개요

Movie Diary는 한 사람의 영화 감상 기록을 저장하는 1인용 앱입니다. 한 줄 평이 아니라 한 편의 기록 — 별점, 본 날짜, 장문 메모, 태그를 같이 남깁니다. 데이터는 로컬 스토리지에 저장하고, 영화 메타데이터(제목/포스터/연도/감독)는 TMDB에서 자동완성으로 채웁니다.

핵심 화면 3개

  • ① Main List — 헤더 + 통계 바 + 필터 + 5열 포스터 그리드
  • ② Detail — 좌측 큰 포스터 / 우측 메타·메모·이전 감상 기록 타임라인
  • ③ Add/Edit Modal — TMDB 자동완성 입력, 별점, 메모, 태그

디자인 원칙

  • 다크 단일 액센트 — 배경은 4단 그레이, 강조는 오직 부드러운 그린(#62D26F) 하나.
  • 포스터가 콘텐츠 — 카드는 포스터 위주, 텍스트는 호버 시 페이드인되는 오버레이로.
  • 고요한 타이포그래피 — Pretendard 산세리프, 굵기 위계만으로 정보 깊이를 표현. 세리프/모노 사용 금지.
  • 여백은 56px 거터 — 페이지 좌우 거터를 한 변수(--gutter-x)로 통일.

3 · 3 화면 사양

3.1 ① 메인 — 영화 목록

구조 (위에서 아래):

  1. App Bar · 좌(로고+네비) / 우(검색 인풋 240px + Primary CTA "새 영화 기록") · 좌우 거터 56px · 보더 1px --rule
  2. Hero stat bar · 좌측 H1 "최근 본 영화" + 서브카피 / 우측 통계 3블록 (총 기록 / 올해 / 평균 별점) · 위아래 패딩 40 / 28
  3. Filter bar · 좌측 정렬 ghost 버튼 4개 (최신순/별점순/연도순/제목순) / 우측 표시 카운트 + 그리드/리스트 토글
  4. Grid · repeat(5, 1fr), gap 32px 24px (row × col) · 이하 카드
  5. Footer · "더 불러오기" ghost 버튼 가운데 정렬

네비 항목: 전체 / 2026 / 좋아요 / 리스트 / 통계. 활성 항목은 액센트 보더 하단 2px + --text 색.

3.2 ② 상세 — 영화 한 편

2단 그리드 380px 1fr, gap 56px:

  • 좌: 큰 포스터(2:3 비율) + 좋아요/리스트에 추가 ghost 버튼 2개
  • 우: 카테고리 라벨 → H1 영화 제목 (44px) → 영문 제목·연도·러닝타임 → 별점(20px)+숫자+감상 일시 → 장르 칩 → Credits 패널(--bg-2, 2열, 감독/각본/주연/촬영/국가/개봉) → 메모 블록(--bg-2, 좌측 3px 액센트 보더) + 사용자 태그 → 이전 감상 기록 타임라인(같은 영화의 과거 별점/메모 행)

3.3 ③ 모달 — 새 영화 기록

720px 패널, 헤더(작은 라벨 NEW ENTRY + H2 제목 + 닫기) → 본문(필드 4개) → 푸터(자동저장 안내 / 취소·저장 버튼).

본문 필드 순서:

  1. 영화 제목 * — 검색 아이콘 + 인풋 + 우측 "검색 중" 펄스, 아래에 자동완성 드롭다운 (포스터 38×56 + 제목 + 영문/연도/감독). 선택된 행은 --accent-soft 배경 + 우측 "선택됨" 라벨.
  2. 본 날짜 * / 별점 * — 2열 그리드. 별점은 인풋 박스 내부에 별 5개 + "4.5 / 5" 텍스트.
  3. 감상 메모 — 멀티라인 textarea(min-height 140), 우측 상단에 글자수 카운터, 우측 하단에 "마크다운 지원" 힌트.
  4. 태그 — 칩 + 인라인 인풋. Enter로 추가, × 클릭으로 제거.

4 · 인터랙션 노트

4.1 카드 호버

  • 카드 자체: transform: translateY(-2px) · 0.18s ease.
  • 포스터 위에 그라디언트 오버레이가 opacity 0 → 1로 페이드인. 안에 별점(13px) + 감상 일시.
  • 카드 클릭 → 상세 화면으로 이동. history.pushState로 URL을 ?id=N으로 갱신.

4.2 별점 입력 (모달 / 상세 inline edit)

  • 마우스 오버 시 각 별의 좌/우 절반에 따라 0.5/1.0 미리보기 표시.
  • 클릭 시 확정. 같은 값을 다시 클릭하면 0.5 감소(취소 동작은 따로 X 버튼이 아니라 토글로).
  • 키보드: ← / →로 0.5씩 조정, 0~5 숫자키로 정수 별점.

4.3 모달 열기 / 닫기

  • 열기: 헤더의 "새 영화 기록" 또는 빈 상태의 큰 CTA. body에 overflow: hidden 추가하여 배경 스크롤 잠금.
  • 닫기 트리거: 우상단 X / 백드롭 클릭 / Esc. 단, 입력값이 있을 때 백드롭 클릭/Esc는 확인 다이얼로그를 띄움.
  • 저장: ⌘/Ctrl + Enter로 폼 제출.
  • 모달 진입 애니메이션: fadeIn .18s (위 키프레임 정의 사용).

4.4 TMDB 자동완성

  • 입력 후 250ms debounce. 빈 문자열이면 즉시 닫힘.
  • 요청 중에는 우측 펄스 인디케이터 + "검색 중" 텍스트 표시.
  • 드롭다운은 인풋 바로 아래 top: calc(100% + 6px). 키보드: ↑/↓로 이동, Enter로 선택, Esc로 닫기. 선택된 행은 좌측 3px 액센트 보더 또는 --accent-soft 배경 + 우측 "선택됨" 라벨.
  • 최대 8개 결과. 결과 0건이면 "검색 결과 없음 — 직접 입력하기" 행을 마지막에 표시.
  • 선택 시 인풋에 한국어 제목 채움 + 영화의 메타데이터(영문제목/연도/감독/포스터 URL/장르)를 hidden 상태로 보관 → 저장 시 함께 기록.

4.5 태그 입력

  • 인라인 인풋에 글자 입력 후 Enter 또는 ,로 칩 추가. 빈 인풋에서 Backspace는 마지막 칩 제거.
  • 중복 태그는 무시 (조용히 reject + 인풋 살짝 흔드는 shake 모션).
  • 칩의 × 클릭 시 즉시 제거.

4.6 정렬 / 필터 / 검색

  • 정렬 ghost 버튼: 라디오 그룹(한 개만 활성). 활성 = .is-active.
  • 네비 "전체 / 2026 / 좋아요 / 리스트 / 통계": 라우팅. 2026은 연도 필터, 좋아요는 liked === true.
  • 검색 인풋(헤더 240px): debounce 200ms 후 클라이언트 사이드 필터 (제목 + 감독 + 메모 모두 검색).

5 · 구현 노트

5.1 반응형 그리드 브레이크포인트

리스트 그리드는 뷰포트에 따라 칼럼 수를 단계적으로 줄입니다:

min-width그리드거터비고
≥ 1280px5 columns56px기본 데스크탑
≥ 1024px4 columns40px좁은 데스크탑 / 큰 태블릿
≥ 720px 3 columns32px태블릿
≥ 480px 2 columns20px큰 모바일

상세 화면의 2단 그리드는 ≥ 900px에서만 유지. 그 이하에서는 1단 stack(포스터 위 280px 정사각 wrap, 그 아래 메타).

모달은 ≥ 768px에서 720px 가운데 정렬, 그 이하에서는 좌우 12px 마진의 풀너비.

5.2 다크 모드 토큰

이 디자인은 다크 only입니다. 라이트 모드는 v1 범위 외. 그래도 향후 추가 가능하도록 모든 색은 :root의 변수로만 참조하세요. 인라인 hex(#fff) 금지. 유일한 예외는 별점 SVG 빈별의 rgba(156,163,175,0.4)와 모달 백드롭의 rgba(20,24,28,0.78) — 이 두 곳만 변수 외 색 허용.

5.3 폰트 로딩

  • Pretendard는 Google Fonts에 없습니다. 반드시 jsDelivr CDN의 pretendard.min.css를 사용 (버전 핀 권장: @v1.3.9).
  • FOUT 방지를 위해 <head> 최상단에 preconnect로 fonts.googleapis.com, fonts.gstatic.com, cdn.jsdelivr.net 3곳 모두 연결.
  • 한글이 다수이므로 font-display: swap은 Pretendard 기본값을 따릅니다 (수정 불필요).

5.4 접근성

  • 모달: role="dialog" aria-modal="true", 열릴 때 포커스를 닫기 버튼이 아닌 첫 인풋(영화 제목)에 이동. 닫힐 때 트리거 버튼으로 포커스 복귀.
  • 별점: role="radiogroup" + 각 별 role="radio" aria-checked. 키보드만으로도 변경 가능.
  • 아이콘 버튼은 모두 aria-label 필수.
  • 태그 칩의 × 버튼: aria-label="태그 제거: #재관람" 형태로 어떤 태그인지 명시.
  • 색대비: --text-muted (#9CA3AF)는 --bg (#14181C) 위에서 7.6:1 — AAA 통과. --text-faint는 보조 정보(글자수 등)에만 사용.

5.5 영화 포스터 이미지

  • TMDB 포스터: https://image.tmdb.org/t/p/w500<poster_path>. 카드는 w342, 상세 hero는 w500이면 충분.
  • 포스터 누락 시 fallback: --bg-2 배경 + 가운데 "NO POSTER" .t-tiny 텍스트.
  • img에는 항상 alt="{영화제목} 포스터", loading="lazy", decoding="async" 지정.

5.6 단일 HTML 패키징 가이드

  • 한 파일 안에 모두 — <style>, <script> 모두 인라인. 외부 의존은 폰트 2개와 (선택) React UMD만.
  • React UMD를 쓰지 않는다면 가벼운 vanilla DOM 렌더 함수로 충분합니다 (영화 카드/별점 등 모두 stateless template로 표현 가능). 인터랙션 상태는 한두 군데(모달 열림, 정렬 키, 검색어)만 있으므로 let state = {…}; render() 패턴이 적합.
  • SVG 별/아이콘은 인라인 사용. 별점은 동일 SVG path를 5번 반복하고 clipPath로 절반 채움.

6 · TMDB API 연동

6.1 인증

  • TMDB v3 API 키를 사용. https://api.themoviedb.org/3/search/movie
  • 키는 환경변수가 아닌 사용자 설정으로: 첫 실행 시 "TMDB API 키 입력" 모달을 띄우고 localStorage.tmdbKey에 저장. 이후 모든 요청에 ?api_key={key}&language=ko-KR.

6.2 검색 엔드포인트

// 영화 제목 자동완성
GET https://api.themoviedb.org/3/search/movie
    ?api_key={key}
    &language=ko-KR
    &query={입력값}
    &include_adult=false
    &page=1

// 응답 매핑 (drop down 표시용)
{
  id, title,                          // → 한국어 제목
  original_title,                     // → 영문/원어 제목
  release_date.slice(0,4),            // → 연도
  poster_path,                        // → image.tmdb.org/t/p/w185 + path
  genre_ids[]                         // → /genre/movie/list 매핑
}

6.3 상세 보강

사용자가 자동완성에서 영화를 선택한 시점에 한 번 더 호출해 감독·러닝타임을 보강:

GET /3/movie/{id}?api_key={key}&language=ko-KR&append_to_response=credits

// 매핑
runtime,                                      // → "1시간 38분"
credits.crew.find(c => c.job === 'Director'), // → 감독
credits.cast.slice(0, 2),                     // → 주연 2명
production_countries[0].iso_3166_1            // → 국가 코드

6.4 레이트 리밋 / 캐시

  • TMDB는 분당 ~50req 제한. 자동완성에 250ms debounce + 동일 query 결과는 5분간 메모리 캐시.
  • 한 번 저장된 영화의 메타데이터(tmdbId, posterPath, …)는 로컬에 그대로 보관해서 재호출 불필요.

7 · 로컬 스토리지 스키마

모든 사용자 데이터는 한 키 movieDiary.v1에 JSON으로 직렬화 저장.

localStorage['movieDiary.v1'] = JSON.stringify({
  "settings": {
    "tmdbKey": "…",
    "sort": "recent",            // recent | rating | year | title
    "view": "grid"               // grid | list
  },
  "entries": [
    {
      "id": "e_2026-04-22_화양연화_3",    // 날짜 + 제목 + 재감상횟수
      "tmdbId": 843,
      "title": "화양연화",
      "originalTitle": "In the Mood for Love",
      "year": 2000,
      "runtime": 98,
      "director": "왕가위",
      "posterPath": "/iYBdgxOuE3rlFXjhU8VZSMfizjV.jpg",
      "genres": ["로맨스", "드라마"],
      "watched": "2026-04-22T23:14:00+09:00",
      "rating": 5,                  // 0.5 단위 0–5
      "note": "복도와 계단, 빨간 벽지의 호텔…",
      "tags": ["#재관람", "#홍콩"],
      "liked": true,
      "createdAt": "2026-04-22T23:14:00+09:00",
      "updatedAt": "2026-04-22T23:18:00+09:00"
    }
  ]
});

주의

  • 한 영화를 여러 번 본 경우는 각 감상이 별도 entry. tmdbId로 묶어서 상세에 "이전 감상 기록" 타임라인 생성.
  • 저장은 updatedAt이 바뀔 때마다 즉시 (모달 입력 중에도 5초마다 자동 임시 저장 → movieDiary.draft 별도 키).
  • 스토리지가 5MB에 근접하면 (대략 5,000편) 경고 토스트 표시.
  • 임포트/익스포트: 설정 화면에 "JSON으로 내보내기" / "가져오기" 버튼. 마이그레이션을 위해 항상 { version: 1, ... } 래퍼 사용.

8 · Claude Code 작업 브리프

목표: 이 핸드오프 파일을 받아 단일 movie-diary.html(외부 의존 = 폰트 + 선택적 React UMD만)로 동작하는 앱을 구현하세요. 데이터는 로컬 스토리지, 영화 메타데이터는 TMDB. 디자인 토큰은 위 :root를 그대로 사용.

최소 요구사항 (MVP)

  1. 3 화면 구현 — 리스트(라우트 /) / 상세(/?id=N) / 모달(?new 또는 ?edit=N).
  2. TMDB 자동완성 검색 + 선택 시 메타 자동 채움.
  3. 별점(0.5 단위), 본 날짜, 메모, 태그 입력 + 로컬 스토리지 저장.
  4. 리스트 정렬 4가지(최신/별점/연도/제목) + 검색(제목·감독·메모) + 좋아요/올해 필터.
  5. 상세에서 같은 영화의 이전 감상 기록 타임라인.
  6. JSON 내보내기/가져오기.
  7. 키보드 인터랙션: 모달 Esc/⌘Enter, 별점 ←→/숫자, 자동완성 ↑↓ Enter Esc.
  8. 반응형 5/4/3/2 column 그리드 + 상세 stack 전환 + 모달 풀너비 전환.

해서는 안 되는 것

  • 다른 액센트 색 추가 금지 (그린 하나만).
  • 이모지로 별점/하트 대체 금지 — 반드시 SVG.
  • 둥근 모서리 8px 이상 사용 금지 (모달만 8px, 나머지는 6 또는 4).
  • 본문 글자 12px 미만 금지. 11px은 .t-tiny UPPERCASE 라벨에만.
  • 외부 UI 라이브러리(MUI, Chakra 등) 사용 금지. 가벼운 vanilla 또는 React UMD까지만.

완료 기준 체크리스트

  • ☐ 새 영화 기록 → 저장 → 새로고침 후에도 카드가 그리드에 보인다.
  • ☐ TMDB 키 미설정 시 첫 실행 안내 모달 표시.
  • ☐ 카드 호버 시 오버레이 페이드인, 상세로 이동.
  • ☐ 모달 Esc 닫기 + 작성 중일 때는 확인 다이얼로그.
  • ☐ 별점 키보드(←→/0–5)로 0.5 단위 조정 가능.
  • ☐ 1280 / 1024 / 720 / 480px 4단계 반응형 정상.
  • ☐ Lighthouse 접근성 ≥ 95.
  • ☐ JSON 내보내기 → 다른 브라우저에서 가져오기 → 동일 상태 복원.
